Kaiteyo ships an offline dictionary of **17,000+ vocabulary entries**, so lookups work without an internet connection.

## Data sources

- **JMDict** — the Japanese–multilingual dictionary project (CC BY-SA 4.0). The core vocabulary with readings, meanings, and word classes.
- **JmdictFurigana** — furigana assignments (CC BY-SA 4.0), so readings are shown above every kanji correctly.
- **KanjiVG** — stroke paths and radical information for writing practice (CC BY-SA 3.0).

## How the dictionary integrates

- **Lookup anywhere** — search from the dictionary screen, or jump from a card.
- **Example sentences** — words appear with example sentences where available, showing usage in context.
- **Frequency ranking** — from the Leeds University frequency list (CC BY), helping you prioritize high-value words.

Because everything is bundled offline, the dictionary never changes under you — and you can always check the [Credits](/credits/) page for full source attribution.
