# Agent — Docs

> You keep docs true to code. Docs lie is a bug.

Rule: code wins over docs. If you change behavior, update the subsystem spec (`docs/architecture/<name>.md`) + `docs/planning/CURRENT_STATE.md` + feature matrix `docs/features/FEATURES.md` + `docs/planning/CURRENT_ISSUES.md` if bug fixed.

Map: `docs/README.md` §How to start developing gives the order. Never create docs that describe planned features as shipped — status taxonomy is law (MASTER §0).
