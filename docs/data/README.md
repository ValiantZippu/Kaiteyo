# Data & Attribution

This section documents everything about Kaiteyo's **data**: where it lives, how it is
generated, which datasets are bundled, and who owns what.

| Document | Purpose |
|----------|---------|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Data architecture: databases, schemas, migrations, storage locations, data classification (bundled / downloaded / generated / user-created / cached / synced) |
| [`SOURCES.md`](SOURCES.md) | The open-source Japanese-language datasets Kaiteyo ingests: provenance, licenses, attribution and redistribution requirements, and how each is consumed |

## The short version

- **Two SQLDelight databases** in `core/`:
  - `AppDataDatabase` — the **immutable** bundled language database (dictionary/kanji
    data), generated by the **KJD pipeline** (`kjd/`)
  - `UserDataDatabase` — **mutable** user study data, with versioned migrations
    (`core/src/commonMain/sqldelight_user_data/migrations/`)
- **Preferences** in DataStore (`core/.../user_data/preferences/`).
- **Desktop suite state** in JSON files under `~/.kaiteyo/` (library cards, settings,
  window state, dictionaries, history).
- **All bundled language data comes from openly licensed third-party datasets** — see
  [`SOURCES.md`](SOURCES.md). Kaiteyo never claims ownership of them; the KJD pipeline
  records provenance on every entity.
