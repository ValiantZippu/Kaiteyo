# User Guide

End-user documentation for Kaiteyo. This guide describes **what the app actually does
today** — implemented features only; planned items are labeled as such.

| Document | Purpose |
|----------|---------|
| [`GETTING_STARTED.md`](GETTING_STARTED.md) | Install, first launch, onboarding, the home screen |
| [`STUDYING.md`](STUDYING.md) | Kanji & kana, vocabulary, writing practice, SRS/review, decks, search, statistics |
| [`DESKTOP_SUITE.md`](DESKTOP_SUITE.md) | The desktop immersion workspace: dictionary, media, mining, OCR, browser |
| [`CUSTOMIZATION.md`](CUSTOMIZATION.md) | Themes, settings, navigation, keyboard shortcuts |

> These guides describe **implemented features only**, and the screen/feature names
> match the actual composables and workspace views (e.g. `LibraryScreen`,
> `StatisticsScreen`, `WorkspaceView` entries). If a guide disagrees with the app,
> the app wins — report it per `../contributing/CONTRIBUTING.md`.

## Which guide do I need?

- **New to the app?** Start with [GETTING_STARTED.md](GETTING_STARTED.md).
- **Studying kanji or vocabulary?** [STUDYING.md](STUDYING.md).
- **Using the desktop app for immersion (reading, video, mining)?**
  [DESKTOP_SUITE.md](DESKTOP_SUITE.md).
- **Making the app yours?** [CUSTOMIZATION.md](CUSTOMIZATION.md).

## Platform coverage

- **Desktop (Windows/macOS/Linux):** the full immersion suite + the shared study engine.
- **Android / iOS:** the shared study engine (kanji, kana, vocabulary, writing, SRS,
  decks, statistics). The desktop-only features (dictionary import, media center, mining,
  OCR, browser, local API) are documented under desktop.
