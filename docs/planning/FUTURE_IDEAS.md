# Kaiteyo — Future Ideas

This document captures ideas for future consideration. Not all ideas will be implemented — they are collected here for discussion and prioritization.

## Learning Features

- **AI-powered review scheduling** — Optimize SRS intervals based on performance patterns
- **Sentence mining** — Extract sentences from imported text and create cards
- **Grammar explanations** — Integrated grammar references
- **Pitch accent diagrams** — Visual pitch accent patterns for words
- **Handwriting recognition** — AI-powered stroke analysis for writing practice
- **Audio pronunciation** — Native speaker audio for vocabulary
- **Reading mode** — Graded texts with integrated lookup

## Community Features

- **Shared decks** — Community-contributed flashcard decks
- **Theme marketplace** — User-created themes shared with the community
- **Study groups** — Shared study goals and progress
- **Leaderboards** — Optional, opt-in progress comparison

## Cloud Features

- **Cross-device sync** — Study progress synced across devices
- **Cloud backup** — Automatic backup of study data
- **User accounts** — Optional accounts for sync and community features

## Platform Features

- **Linux Snap/Flatpak** — Additional Linux distribution formats
- **Web version** — Browser-based version for Chromebooks and shared computers
- **Chrome OS** — Native Chrome OS support
- **Wear OS** — Flashcard review on smartwatches

## Technical Ideas

- **Plugin system** — Extend Kaiteyo with community plugins
- **Custom card templates** — User-defined card layouts with HTML/CSS
- **Scripting API** — Automate tasks with scripts
- **Offline TTS** — Text-to-speech without internet
- **OCR integration** — Scan Japanese text from images

## UI Ideas

- **Split view** — Multiple study modes visible simultaneously
- **Focus mode** — Distraction-free study environment
- **Custom layouts** — User-arranged panel layouts
- **Dynamic island** — macOS-style notification island for study reminders
- **Live wallpaper** — Animated backgrounds that respond to study activity

## How Ideas Become Features

1. Idea is added to this document
2. Community discussion and feedback
3. Prioritization in roadmap
4. Feature specification written
5. Implementation planned
6. Development and testing
7. Release
