# 📋 planning — Kaiteyo Project Planning

This directory is the brain of the project. It contains the living task tracker, issue tracker, changelog, and roadmap.

## Contents

| File | Purpose |
|------|---------|
| `TODO.md` | Master task list with priorities |
| `CURRENT_ISSUES.md` | Living bug/issue tracker |
| `CHANGELOG.md` | Human-readable release history |
| `COMPLETED.md` | Completed features by version |
| `FUTURE_IDEAS.md` | Ideas for future consideration |

Vision, roadmap, and milestone plans live in `../roadmap/`
(`PROJECT_VISION.md`, `ROADMAP.md`); the design language lives in
`../design/DESIGN_LANGUAGE.md`.

## Priority Levels

| Priority | Meaning |
|----------|---------|
| 🔴 P0 | Critical — blocks usability, must fix immediately |
| 🟡 P1 | High — important for next release |
| 🟢 P2 | Medium — planned for current milestone |
| 🔵 P3 | Low — nice to have, future consideration |

## Workflow

1. Check `CURRENT_ISSUES.md` for known problems
2. Check `TODO.md` for prioritized tasks
3. Implement fixes (P0 first, then P1, etc.)
4. Update `CHANGELOG.md` when changes are made
5. Move completed items to `COMPLETED.md`
6. Update `CURRENT_ISSUES.md` when issues are resolved
