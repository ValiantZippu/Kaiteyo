# Screenshots

Visual assets for the Kaiteyo documentation.

## Convention

- Real screen captures (PNG) replace the schematic mockups as they become
  available — run the app and capture the actual window.
- Naming: `kebab-case-what-it-shows.png`, e.g. `window-shell.png`.
- Reference from docs with relative paths: `../screenshots/window-shell.png`.
- Keep captures unedited (no annotations in the image itself); describe callouts
  in the surrounding prose.

## Capturing

`scripts/capture-window-shell.sh` captures every launcher state deterministically:
it launches Kaiteyo once per state with the dev-only `--capture-state=` flag
(fixed 1200×800 window, pre-opened state, self-exit after a dwell), then grabs
the window — xdotool+ImageMagick on Linux, `screencapture` on macOS, Win32 via
PowerShell on Windows. Run `./scripts/capture-window-shell.sh` for all four
states, or pass a single state name. Once the PNGs look right, delete the SVG
mockup.
